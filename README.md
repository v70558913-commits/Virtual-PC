🖥️ SOBRE O PROJETO

O Virtual PC OS é um ambiente computacional virtual que busca oferecer uma experiência imersiva de utilização de um computador, reunindo interface gráfica, aplicativos e ferramentas em um único sistema.

⚙️ FUNCIONALIDADES

- Desktop interativo
- Gerenciamento de janelas
- Navegador virtual
- Terminal integrado
- Gerenciador de arquivos
- Painel de configurações
- Interface de usuário interativa
